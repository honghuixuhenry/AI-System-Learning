# Lesson 133
# RAG & External Knowledge

This lesson demonstrates
the core RAG architecture.

Pipeline:

Query
→ Retrieve
→ Rank
→ Build Context
→ LLM

Key concepts:

- documents and chunks
- keyword retrieval
- semantic retrieval
- vector databases
- hybrid retrieval
- metadata filtering
- reranking
- context construction
- grounding
- citations
- RAG security

Important distinctions:

RAG != Agent Memory

RAG != Vector Database

RAG != Fine-Tuning

Vector databases are
retrieval infrastructure.

RAG retrieves external
knowledge at inference time.
