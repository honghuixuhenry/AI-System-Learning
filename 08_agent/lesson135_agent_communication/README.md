# Lesson 135
# Agent Communication & Coordination

This lesson introduces
communication patterns
for multi-agent systems.

Core architecture:

Agent
→ Structured Message
→ Message Bus
→ Agent

Important concepts:

- message schema
- sender and receiver
- message IDs
- task IDs
- request-response
- asynchronous messaging
- direct messaging
- publish/subscribe
- task handoff
- acknowledgments
- task ownership
- timeout and retry
- deadlock and livelock
- message security

Agent communication
should be treated
like an internal API.

Free-form natural language
should not automatically
become control messages.
